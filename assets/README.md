# Vendored assets

## `silero_vad.onnx`

Silero VAD, ONNX build, **vendored deliberately** — the `silero-vad` PyPI
package imports `torch` unconditionally at module scope, including on its
`onnx=True` path, and a second CUDA runtime alongside CTranslate2 on a 4 GB card
is a real failure rather than a theoretical one. See **D35**. Never add the
package as a dependency; load this file with `onnxruntime` instead.

| | |
|---|---|
| Source | `silero_vad` 6.2.1, `silero_vad/data/silero_vad.onnx` |
| License | MIT (`silero_vad.LICENSE`, Silero Team) |
| Size | 2 327 524 bytes |
| SHA-256 | `1a153a22f4509e292a94e67d6f9b85e8deb25b4988682b7e174c65279d8788e3` |

Model interface, confirmed against this file — **corrected in D53**:

```
inputs : input [N, 576] float32 · state [2, N, 128] float32 · sr int64
outputs: output [N, 1] float32  · stateN [2, N, 128] float32
```

**576, not 512.** This is Silero v5: each call takes the 512 new samples with 64
samples of the *previous* frame prepended. The ONNX input dimension is dynamic,
so a 512-wide call runs and returns a number — it just returns **0.0005 on real
speech** instead of 1.0. Two things therefore carry between frames, not one: the
LSTM `state`, and a 64-sample audio context. This file said 512 until D53
measured it. Frames on the wire are still 512 samples (D23); the context lives
inside the VAD.

Measured cost **0.116 ms per 32 ms frame** at the correct 576 width, single
threaded, on the dev laptop — inside D35's 0.156 budget. `doctor` re-measures it
on whichever machine it runs on, and now also asserts that speech reads high and
silence reads low, so a dead VAD fails the preflight instead of passing it.

## `speech_fixture.wav`

Generated speech. The repo's only audio that Silero rates as speech, and
therefore the only thing that makes a **positive** VAD test possible on a
machine with no meeting recording. See **D56**.

| | |
|---|---|
| Source | Generated by `speech_translator/tools/make_speech_fixture.py` |
| Engine | espeak-ng 1.51 (`libespeak-ng.so.1`), default voice, formant synthesis |
| Content | Three English phrases separated by 900–1000 ms of digital silence |
| Format | 13.92 s · 16 000 Hz mono int16 (the pipeline's own frame format) |
| Size | 445 400 bytes |
| SHA-256 | `43c83076046c59457d3af42fd6f2880713d6d5a965e964b8158839917443a14c` |

**Why generated rather than downloaded.** espeak-ng's default voice is formant
synthesis — the output contains no recorded audio and embeds no third-party
sample, so vendoring it raises no licensing question that a clip from the web
would. mbrola voices are recorded diphones and are deliberately *not* used.
Regenerating it byte-for-byte takes one command on any box with espeak-ng
installed.

**What it does not do.** TTS speech has no room tone, no music bed, no
overlapping speakers and no reverb — precisely the things D23 chose Silero to
survive. This fixture proves the VAD is wired up and the segmenter's state
machine behaves; it is **not** a substitute for `PLAN.md`'s captured meeting WAV,
which stays owed in `STATE.md`.
